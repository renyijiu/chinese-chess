# U6 roster review

`roster-contact-sheet-red-black.png` is generated by
`scripts/blender/render_roster_contact_sheet.py` from the LOD1 authoring GLBs.
Columns are advisor, elephant, chariot, horse, cannon, and soldier; the upper
row is the red faction and the lower row is the black faction.

The fixed orthographic camera is for silhouette, faction-palette, footprint,
and base-grounding review. It is not a marketing render or a replacement for
the six-view concept sheets.

`roster-board-red-black-browser.png` is the Playwright-captured real WebGL2
board after starting a fresh 32-piece game. It verifies that the same runtime
RGB semantic mapping renders the near red army in vermilion/gold and the far
black army in ink-green/bronze while preserving hide, skin, wood, ivory, iron,
and stone colors. The only browser console error in that isolated session was
an unrelated missing `/favicon.ico`; the in-app browser refresh recorded no
post-fix scene error.
